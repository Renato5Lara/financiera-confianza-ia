# Laboratorio: Sistemas de Información Integrados con IA

Código fuente del trabajo individual *Transformación operativa y prevención de fraudes en Financiera Confianza Perú*
(Universidad Privada Antenor Orrego, Ingeniería de Sistemas e Inteligencia Artificial). Autor: Rodríguez Lara, Franklin Renato.

| Carpeta | Contenido | Datos |
|---|---|---|
| `machine_learning/` | Riesgo crediticio: logística, Random Forest, Gradient Boosting e Isolation Forest | Público (UCI, CC BY 4.0) |
| `deep_learning/` | CNN en PyTorch para clasificación de imágenes | Público (incluido en scikit-learn) |
| `mineria_procesos/` | PM4Py: descubrimiento, conformidad y mejora | Simulado |
| `analisis_electoral/` | Bluesky + Transformer de sentimiento; reconstrucción de las elecciones Perú 2026 | Real, agregado (sin textos) |
| `evaluacion_ux/` | Inspección ISO/IEC 25010 de la interfaz ERP (antes y después) | Datos ficticios de la interfaz |

Cada carpeta tiene su `README.md`, `requirements.txt`, código comentado y resultados de la ejecución.
Probado con Python 3.13 (scikit-learn 1.9, pandas 3.0, torch 2.15 CPU, pm4py 2.7, pysentimiento 0.7) y Node.js 22 (Playwright).
